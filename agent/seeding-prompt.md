### Data and Seeding

**Data Sources:**
*   Initial data is stored in `database/data/` in CSV format:
    *   `users.csv`
    *   `team.csv`
    *   `player.csv`

**Seeders:**
*   Use the following seeders to populate the database:
    *   `UserSeeder`: Loads `users.csv`.
    *   `TeamSeeder`: Loads `team.csv`.
    *   `PlayerSeeder`: Loads `player.csv`.

**Instruction:**
*   Use this data to initialize the application state during deployment or testing.
